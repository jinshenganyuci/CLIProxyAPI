# 客户端 API Key 备注

从 `v8.0.59-codex-identity.4` 起，配置页面的客户端 API Key 支持服务端备注。备注显示在每行密钥掩码之前；没有备注时显示“未备注”。例如可填写“手机聊天”“工作电脑”或“自动化脚本”。

在对应行点击“备注 / 编辑”，填写可选备注并更新，再使用配置页面的保存操作确认变更。备注与其他可视化配置一样先进入草稿，取消或放弃未保存的修改不会写入服务器。备注最长 120 个字符，可清空。

备注随配置保存在服务器，刷新、切换浏览器和服务重启后仍可读取。此前仅保存在单个浏览器中的本地名称不会自动覆盖服务端备注。备注会在下一次目录同步与页面刷新后显示在流量统计的密钥列表中。

备注不修改实际 API Key、不改变鉴权或凭据绑定，也不改变流量统计 ID 和累计。密钥排序不会导致备注互换；同一个实际密钥使用同一备注。显式删除或替换密钥时，可视化编辑器同步处理对应备注。

服务端配置使用 `access.api-key-notes` 映射保存备注，索引为实际密钥去除首尾空白后的 SHA-256 小写十六进制摘要。`access.api-keys` 保持原有字符串数组结构。备注通过现有 v8 配置管理接口和版本校验保存，不新增公开接口。
